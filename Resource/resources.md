> **文档版本：2026-10-08**（基于当前 `index.html` 实际运行状态，所有坐标/尺寸/色值/字号均由沙盒实测抓取）
> **目的：本项目要迁移到另一个 AI 网站。把本文档 + 下述资源包发给目标环境的 AI，应能复刻出一模一样的游戏。**
>
> 复刻总则：
> 1. 单文件 HTML5 canvas 游戏，画布固定 **1920×1080**（不响应式缩放，整机 16:9）。
> 2. 所有视觉规格以下文为准；坐标均为**画布像素**（左上原点）；字号单位 **pt**（`PT = 96/72 ≈ 1.3333`，1pt=1.3333px）。
> 3. 资源加载用相对路径 `Resource/images/`、`Resource/fonts/`；图片失败回退矢量绘制（见 §7 各条）。
> 4. 测量方法：沙盒加载脚本 + 假 canvas 记录全部 drawImage/fillText 实参。复核时同法。

## 5. 游戏机制（完整规则）

### 5.1 状态机

```
boot(2s 整机图，点击/按键跳过) → ready(初始界面) → playing →〔破解成功〕1s 展示窗(冻结)
                                        → win-hold(画面停住，点击/按键确认) → win(成功结算)
playing →〔lives=0〕→ dead-restart(失败结算) → 点击/按键 → 重开(playing)
```

- **破解成功**：progress≥100 或吃完全部豆 → `cracked=true`，1 秒展示窗（冻结移动/碰撞，角色换 `Player_01` + `Player_Eff` 特效、进度条满黄）→ `win-hold` 等确认 → `win`。
- **死亡**：被抓 → lives--；>0 则回出生点（invulnT=1s 无敌闪烁，α 在 0.4/1 间按 0.1s 交替）；=0 → `dead-restart`。

### 5.2 进度（2026-10-08 版）

- **每颗普通豆 +1%**；高价值豆 = +1% 再额外 +2~10%（`bonusProgress` 累计）。
- `progress = eaten + bonusProgress`，上限 100。**吃约 100 颗即 100% 提前获胜**（全图 358 颗，不必吃完）。
- KEY 揭示档位 25/50/75/100%（KEY 密码来自 `key.json` 的 `key` 字段，4 字符，默认 "1337"）。

### 5.3 高价值豆（特殊字符）

| 参数 | 值 |
|---|---|
| 触发概率 `VALUE_BEAN_ODDS` | 0.05（每局一次判定；95% 的局一颗都没有） |
| 数量 `VALUE_BEAN_MAX` | 触发时随机 1~4 个 |
| 加成 `VALUE_BONUS_MIN/MAX` | 每个随机 +2~10% |
| 间距 `VALUE_BEAN_GAP` | 两颗之间 Chebyshev ≥4 格（防字形叠压） |

生成：豆子全量 Fisher-Yates 洗牌后贪心挑满 want 个（间距约束）；每局重开重建（**必须清零 valueGrid**，否则跨局累积）。
样式：22.67px(17pt) GameDrift `#ffd012` + 轮廓 1pt `#d55d21`（Outline Blur 5pt）+ 投影 `#d55d21` 偏移 x3pt y3pt。
普通豆：12px(9pt) GameDrift `#fff6e0`，无轮廓。

### 5.4 移动 / 碰撞 / 敌人 AI

- **玩家**：键盘方向键/WASD；**纯轴向移动**（按哪个键只改那根轴），无车道吸附；`wallLimit` 把身体边缘挡在墙外。
- **敌人 AI**：沿当前方向直行；仅在「被墙挡」或「到达格中心且路口（≥3 开口）且冷却结束（0.35+rand0.5s）」时重选方向；重选时避开回头路（无路可走才允许掉头）；同方向**直行概率 72%**。首帧 snap 到所在格中心。
- **抓捕**：无敌外，玩家-敌人中心距 < 22.15px（CELL×1.8）即被抓。

### 5.5 吃豆与离屏层

- 豆子画在**离屏层 `dotsLayer`**（与墙体 `mazeLayer` 分层，每帧按序合成到主画布）。
- 判定：扫描玩家周围 ±3 格；普通豆半径 14.15px、高价值豆 35.08px（= 其可视尺寸，字形外扩 ±23px）。
- 吃掉一颗后：`clearRect` **±3 格**（覆盖最大字形），再把 **±5 格内仍存在的豆子按原样重画**（否则会削掉邻居高价值豆的光晕）。

## 8. 复刻注意事项（本项目踩过的坑）

1. **结算界面整屏覆盖**：结算先画背景层再画结算元素 → 对局内表现（成功态角色/特效/满条）只在展示窗+win-hold 可见。
2. **离屏豆子层局部擦除**：高价值豆字形外扩 ±23px ≫ 1 格（12.3px）→ 擦 ±3 格、重画 ±5 格，否则削字/残字。
3. **buildMaze 类重建必须清零全部网格**（曾漏 valueGrid → 特殊豆跨局累积叠字）。
4. **出生矩形必须校验**（2×2 全道路，否则 BFS 起点失效 → 整局 0 颗豆子）。
5. **带光晕素材的"视觉大小"按不透明主体算**（Prop.png 红实体 54/88，整图缩放会小一半）。
6. **file:// 字体被 CORS 拦**，必须 http 服务。
7. **素材"尺寸"≠"绘制尺寸"**：见 §7 表头三分类。
8. **大字渲染顺序**：先 strokeText（轮廓）后 fillText（填充+shadow blur 36px）。
9. **HP 无投影**（只有描边）；红心右缘=对齐线+15pt。
